## 4. 目标变量与提交格式

- **标签**：`常住人口（万人）`，来自「人口规模.xlsx」
- **预测目标**：40 座城市 2023 年常住人口，共 40 条
- **提交文件**：`outputs/submission.csv`，字段与顺序须与 `submission_sample.csv` 严格一致：

```csv
city_id,year,count
city1,2023,1234.56
city2,2023,876.54
```

## 5. 清洗与特征工程后的新增字段（由代码生成）

| 字段 | 计算方式 | 单位 | 说明 |
|---|---|---|---|
| `city_id` | 由「城市名称 / 城市」重命名 | - | 统一主键，修正 `ctiy31`→`city31`、`ctiy22`→`city22` |
| `year` | 由「年份」转换，去掉「年」字 | 年 | Int64 |
| `pop_diff` | 常住人口 − 上年常住人口 | 万人 | 必做衍生特征 |
| `pop_growth_rate` | `pop_diff / 上年常住人口` | 比率 | 必做衍生特征 |
| `pop_flow_ratio` | `(常住人口 − 户籍人口) / 户籍人口` | 比率 | 必做衍生特征（净流入率） |
| `pop_diff_lag1` 等 | 上述三者的滞后一期值 | - | **建模用**，规避标签泄漏 |
| `year_since_2000` | `year − 2000` | 年 | 选做特征（时间趋势编码） |
| `urb_gap` | 城镇化率的年度变化 | 百分点 | 选做特征 |
| `wage_growth` | 工资同比增长率 | 比率 | 选做特征 |
| `ratio_0_14` | 0-14 岁人口 / 三年龄段合计 | 比率 | 选做特征（少儿占比） |
| `ratio_65plus` | 65+ 人口 / 三年龄段合计 | 比率 | 选做特征（老年占比） |
| `old_child_ratio` | `ratio_65plus / ratio_0_14` | - | 选做特征（老少比） |
| `pop_log_growth` | `ln(常住人口_t / 常住人口_{t−1})` | 比率 | **建模目标**（对数增长率） |
| `prev_pop` | 上一年常住人口 | 万人 | **还原锚点**，预测时 `pop_t = prev_pop × exp(ĝ)` |

## 6. 已知数据质量问题（清洗时必须处理）

1. **城市名拼写错误**：原始数据中 `ctiy31`、`ctiy22`，需修正为 `city31`、`city22`
2. **年份格式不统一**：部分表年份形如 `2001年`，部分为浮点数 `2011.0`，需统一为整数
3. **表头不在第一行**：生活水平 6 个 Sheet 首行是英文指标名，第 2 行才是真表头
4. **宽长表混用**：工资水平、生活水平为宽表，需 `melt` 转长表
5. **时间跨度参差不齐**：人口密度 2000 年起、人口规模 2001 年起、生活水平 2011 或 2015 年起
6. **早期年份城市覆盖不全**：人口规模 2001—2006 年仅 16—27 城，2007 年起才补齐 40 城
7. **年龄结构仅 3 个普查年**：2000/2010/2020，逐年线性插值属**强假设**，会引入人工噪声（报告必须说明）
8. **横向合并易产生笛卡尔积**：附表若存在重复「city_id + year」键，须先去重再 merge
